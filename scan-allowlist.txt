# Central allowlist for the TruffleHog image scan.
#
# Format: one entry per line, "<Detector> /<path pattern>".
# - Detector is the TruffleHog DetectorName (case-insensitive), for example Box.
# - The path pattern is gitignore-style and matches absolute paths in the image.
#   It must start with "/" so it matches only at the image root.
# - An entry with a missing detector or a relative path fails the scan.
#
# Rules:
# - The scan runs with verification off, so every finding is unverified. An
#   entry suppresses unverified findings of its detector on its path. It can
#   hide a live secret of that detector on that path, so keep entries narrow.
# - The scanner never suppresses a finding marked verified or one with a
#   verification error.
# - Add an entry only for a false positive seen in a real scan. Above it, name
#   the matched content, the image, the owning package, and the run or repo
#   that showed it.
# - Repositories cannot extend this list. A repo-level .truffleignore is ignored.
