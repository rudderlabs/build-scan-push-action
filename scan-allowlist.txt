# Central allowlist for the TruffleHog image scan.
#
# Format: one entry per line, "<Detector> /<path pattern>".
# - Detector is the TruffleHog DetectorName (case-insensitive), for example Box.
# - The path pattern is gitignore-style and matches absolute paths in the image.
#   It must start with "/" so it matches only at the image root.
# - An entry with a missing detector or a relative path fails the scan.
#
# Rules:
# - Each entry needs one detector, one anchored path pattern, and evidence.
# - Evidence: the base image digest that shows the finding with no app code,
#   the matched content, and the package that owns the file.
# - An entry suppresses unverified findings only. The scan never enables
#   verification, because verification sends candidate strings to third-party APIs.
# - Repositories never add their own ignores. A repo-level .truffleignore is ignored.
